Engineering highlights

  • Ledger-first data model. Batches, per-material stock and reports are all recomputed from stock_transaction rows. No derived number is edited by hand.
  • FIFO issue with row locks. Stock issue picks batches oldest-first under SELECT … FOR UPDATE. Returns are traced back to the batches that production line originally took.
  • Validation gates. Receiving is blocked on missing monthly exchange rates, a closed period, over-receipt or open data-quality warnings.
  • Safe verification. Changes are simulated inside a transaction on a cloned database and rolled back. Row counts before and after are compared before anything is applied.
