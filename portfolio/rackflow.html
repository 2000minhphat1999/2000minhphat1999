Problem & objective

Warehouse workflows need consistent stock information and clear records of operational actions. RackFlow models these flows in a small ERP/WMS portfolio application.

My role

Personal project. I define the scope and implement the application incrementally; this is not represented as a deployed customer system or a production warehouse platform.

Current scope

  • Inbound receiving and inventory lookup
  • Order lookup and stock reservation
  • Event history for operational traceability

Implementation

Python services using FastAPI and Flask, SQLAlchemy and PostgreSQL. The project focuses on business rules, data persistence, workflow behavior and explicit state changes.

Evidence & limitations

The features listed above define the current portfolio scope. Outbound workflows and AI-assisted operations remain under development; no production deployment or business KPI is claimed here.

Next step

Complete and verify manual outbound first, then add AI-assisted operations with validation, human confirmation and traceable events. Public source/demo links will be added only when ready to share.
