Fabric Defect Inspection

A planned Computer Vision portfolio experiment for fabric inspection. It is not presented as implemented, trained or validated. The aim is to test whether fabric defects can be detected consistently before considering any factory integration.

01DatasetFind a suitably licensed dataset and inspect class balance.
02BaselineDefine defect classes and train a repeatable baseline.
03EvaluationReport precision/recall, failure cases and limits before any integration claim.
Planning stage

Problem and target

Fabric defects can affect material quality in sofa manufacturing. The proposed goal is to test whether visible defects can be detected consistently before considering any factory workflow integration.

Proposed technical approach

First inspect the dataset and annotations; then build a reproducible baseline suited to the label format. Object detection, segmentation or a classical image-processing baseline should be selected only after examining the data.

Evaluation plan

Report precision, recall and per-class errors. If the selected task is object detection, document mAP and false-negative cases; include representative failures and split rules to reduce leakage.

Current status and limits

This is a portfolio proposal only. No dataset has been selected, code implementation, training, model evaluation or factory integration has been completed or verified for this project.

NEXT STEP: confirm dataset licensing and inspect sample images before choosing a model or claiming any result.
